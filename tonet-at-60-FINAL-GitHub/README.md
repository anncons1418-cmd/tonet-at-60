# Tonet @ 60

GitHub Pages-ready birthday invitation website for Anthony “Tonet”.

## Publish with GitHub Pages

1. Create a public GitHub repository named `tonet-at-60`.
2. Upload **all files from this folder** to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then Save.
6. GitHub will publish the site at:
   `https://YOUR-USERNAME.github.io/tonet-at-60/`

## Important RSVP note

GitHub Pages hosts static files only, so the RSVP page needs a separate form backend.
Before sharing the invitation publicly, connect the RSVP button/form to Google Forms,
Formspree, or another form service so responses can be stored.
